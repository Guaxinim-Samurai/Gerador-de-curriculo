Este projeto é um gerador de currículos dinâmico desenvolvido em PHP, com interface em HTML, CSS e JavaScript.
O objetivo é permitir que o usuário preencha um formulário com seus dados pessoais, experiências, formações e habilidades, e em seguida gere automaticamente um currículo formatado pronto para impressão ou exportação em PDF (via navegador).# Gerador-de-curriculo
